# A股交易规则手册

来源：上海证券交易所交易规则、深圳证券交易所交易规则、证券法

---

## 一、交易时间

| 时段 | 时间 | 说明 |
|------|------|------|
| 集合竞价（开盘前） | 9:15 - 9:25 | 接受买卖申报 |
| 不可撤单 | 9:20 - 9:25 | 只接受申报不接受撤单 |
| 连续竞价（上午） | 9:30 - 11:30 | 持续撮合交易 |
| 午间休市 | 11:30 - 13:00 | 闭市 |
| 连续竞价（下午） | 13:00 - 15:00 | 持续撮合交易 |
| 大宗交易 | 15:00 - 15:30 | 盘后大宗交易 |

> 集合竞价：9:15-9:25系统对全部申报集中撮合，产生开盘价
> 尾盘集合竞价（深交所）：14:57-15:00

## 二、交易单位

- **申报数量**：买入需为100股（1手）或其整数倍
- **零股处理**：卖出可不足100股（如分红产生零股），一次性卖出
- **单笔最大申报**：通常不超过100万股

## 三、涨跌幅限制

| 板块 | 涨跌幅 | ST/\*ST |
|------|--------|----------|
| 主板 | ±10% | ±5% |
| 科创板 | ±20% | - |
| 创业板 | ±20% | ±20% |
| 北交所 | ±30% | - |
| 新股首日 | 无限制 | - |

> 新股上市前5个交易日不设涨跌幅限制
> 退市整理期股票涨跌幅±10%

## 四、T+1交易制度

- **买入**：当天买入股票，当天不可卖出，T+1日方可卖出
- **卖出**：当天卖出股票所得资金，当天可用于买入其他股票
- **资金可取**：卖出股票所得资金，T+1日方可转出至银行账户

## 五、交易费用

| 费用类型 | 费率 | 收取方式 |
|----------|------|----------|
| 印花税 | 成交金额的0.05% | 仅卖出时单边征收 |
| 佣金 | 最高0.3%（可协商） | 买卖双边收取 |
| 过户费 | 成交金额的0.001% | 买卖双边收取 |
| 规费（经手费+证管费） | 已包含在佣金中 | - |

## 六、交易规则要点

1. **价格优先、时间优先**：较高买价优先于较低买价，较低卖价优先于较高卖价
2. **最小变动价位**：A股为0.01元
3. **申报价格范围**：
   - 集合竞价：无价格限制（科创板有前收盘价±30%限制）
   - 连续竞价：不得超出当日涨跌幅限制
4. **ST处理**：
   - ST（特别处理）：近两年亏损、净资产为负等情况
   - *ST（退市风险警示）：更严重，有退市风险
5. **临时停牌**：
   - 无涨跌幅限制股票：盘中涨跌≥30%或≥60%停牌10分钟

## 七、新股申购规则

1. **市值要求**：T-2日前20个交易日日均持有1万元以上非限售A股
2. **申购额度**：每1万元市值可申购1000股（沪市）或500股（深市）
3. **申购方式**：无需缴款，中签后缴款
4. **中签缴款**：T+2日16:00前确保账户有足够资金
5. **连续弃购**：12个月内3次中签未缴款，6个月内禁止打新

## 八、融资融券规则

1. **开通条件**：开户满6个月，资产50万以上
2. **保证金比例**：融资买入/融券卖出保证金比例≥100%
3. **维持担保比例**：≥130%，低于130%需追加担保品
4. **强制平仓**：维持担保比例<130%且未追加，券商强制平仓
5. **标的范围**：交易所公布的融资融券标的股票名单
