# RAG 工单12 项目思维导图

```
RAG 工单12 -- 基于 PDF 文档的智能问答系统
├── 1. 文档处理层
│   ├── PDF 解析
│   │   ├── PyMuPDF (主选)
│   │   └── pdfplumber (备选，支持表格)
│   ├── 文档清洗
│   │   ├── 去水印/保密标记
│   │   ├── 去页眉页脚/页码
│   │   ├── CJK 字符归一化
│   │   └── 表格噪音清理
│   └── 智能分块
│       ├── 按字符数切分 (chunk_size=300)
│       ├── 相邻块重叠 (overlap=100)
│       └── 保留元数据 (来源/页码)
│
├── 2. 索引存储层
│   ├── 向量存储 -- Milvus
│   │   ├── Embedding: m3e-base (768维)
│   │   ├── 支持增量更新
│   │   └── 批量插入优化
│   ├── BM25 索引
│   │   ├── jieba 中文分词
│   │   ├── 词频统计 (TF)
│   │   └── 逆文档频率 (IDF)
│   └── 知识图谱 -- Neo4j
│       ├── 实体抽取 (GraphBuilder)
│       ├── 关系三元组
│       └── 图谱检索
│
├── 3. 检索层 -- HybridRetriever
│   ├── 向量语义检索
│   │   └── Milvus cosine 相似度
│   ├── BM25 关键词检索
│   │   └── jieba 分词匹配
│   ├── 图谱检索
│   │   └── Neo4j Cypher 查询
│   ├── 加权融合 (RRF)
│   │   ├── BM25 权重: 0.4
│   │   ├── 向量权重: 0.6
│   │   └── 图谱权重: 0.3
│   └── Reranker 精排
│       └── bge-reranker-base
│
├── 4. 生成层 -- RAG Pipeline
│   ├── Query 改写 (指代消解)
│   ├── 多轮对话记忆
│   │   ├── Redis 短期记忆
│   │   └── QA 缓存 (Milvus)
│   ├── LLM 生成
│   │   ├── 小米 mimo-v2.5
│   │   └── 流式输出
│   └── 兜底机制
│       ├── 检索内容兜底
│       └── 结构化答案提取
│
├── 5. LightRAG 优化 (工单12)
│   ├── 知识图谱构建
│   │   ├── LightRAG (HKU)
│   │   ├── 中文实体抽取
│   │   ├── 双层检索 (local + global)
│   │   └── 增量更新
│   ├── 对比评估
│   │   ├── 16个测试问题
│   │   ├── RAGAS 评估指标
│   │   │   ├── Faithfulness
│   │   │   ├── Answer Relevancy
│   │   │   └── Context Relevancy
│   │   └── 结果可视化
│   └── 知识图谱可视化
│       └── HTML 交互式图谱
│
├── 6. Web 服务层
│   ├── Flask Web UI
│   ├── SSE 流式输出
│   ├── 文件上传管理
│   └── 会话管理
│
└── 7. 基础设施
    ├── Docker 部署
    │   ├── Milvus (19530)
    │   ├── Neo4j (7474)
    │   ├── Redis (6379)
    │   └── PostgreSQL (5432)
    ├── 配置管理 (.env)
    ├── 日志系统
    └── 安全机制
        ├── JWT 鉴权
        └── 内容过滤
```
