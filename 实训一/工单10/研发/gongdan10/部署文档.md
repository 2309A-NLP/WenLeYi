# gongdan10 RAG 项目 Docker 部署文档

## 一、项目概述

基于 Docker 部署的 RAG（检索增强生成）系统，包含以下组件：

| 组件 | 镜像/版本 | 端口 | 用途 |
|---|---|---|---|
| gongdan10-app | 自建 gongdan10-app | 5000 | Flask RAG 应用（主服务） |
| milvus-standalone | milvusdb/milvus:v2.6.7 | 19530 | 向量数据库 |
| redis | redis:latest | 6379 | 短期记忆缓存 |
| neo4j-rag | neo4j:5-community | 7474/7687 | 知识图谱 |
| attu-local | zilliz/attu:latest | 8000 | Milvus GUI 管理工具 |
| redisinsight | redis/redisinsight | 5540 | Redis GUI 管理工具 |

## 四、部署步骤

### 4.1 构建镜像

```bash
cd D:\桌面\gongdanzuoye\gongdan10
docker build -t gongdan10-app .
```

> 首次构建约需 15-20 分钟（下载 PyTorch CPU + Python 依赖），后续构建利用缓存约 2-3 分钟。

### 4.2 启动 Neo4j（知识图谱）

```bash
docker run -d ^
  --name neo4j-rag ^
  -p 7474:7474 ^
  -p 7687:7687 ^
  -v neo4j-rag-data:/data ^
  -e NEO4J_AUTH=neo4j/neo4j123 ^
  neo4j:5-community
```

- 访问地址：http://localhost:7474
- 用户名：`neo4j`
- 密码：`neo4j123`

### 4.3 启动 RAG 应用

```bash
docker run -d ^
  --name gongdan10-app ^
  -p 5000:5000 ^
  -v D:\桌面\模型\:/models:ro ^
  -v .\documents:/app/documents ^
  -v .\uploads:/app/uploads ^
  -v .\vector_store:/app/vector_store ^
  --env-file .env.docker ^
  --add-host=host.docker.internal:host-gateway ^
  gongdan10-app
```

### 4.4 验证部署

```bash
# 查看所有容器状态
docker ps

# 查看应用日志
docker logs gongdan10-app

# 查看实时日志
docker logs -f gongdan10-app
```

访问 http://localhost:5000 即可使用。

## 五、环境配置 (.env.docker)

```env
# ========== 分块参数 ==========
CHUNK_SIZE=300
CHUNK_OVERLAP=100

# ========== 向量库 ==========
VECTOR_BACKEND=milvus
MILVUS_HOST=host.docker.internal
MILVUS_PORT=19530
MILVUS_COLLECTION=rag_chunks

# ========== 检索参数 ==========
SEARCH_MODE=hybrid
TOP_K=8
BM25_TOP_K=8
FAISS_TOP_K=8
RRF_K=60
SIMILARITY_THRESHOLD=0.3

# ========== 加权融合 ==========
BM25_WEIGHT=0.4
VEC_WEIGHT=0.6

# ========== Embedding 模型 ==========
EMBEDDING_MODEL_PATH=/models/m3e-base

# ========== Reranker ==========
ENABLE_RERANKER=1
RERANKER_MODEL_PATH=/models/bge-reranker-base
RERANK_TOP_K=3

# ========== LLM ==========
LLM_API_KEY=你的sk-开头的key
LLM_API_BASE=https://api.xiaomimimo.com/v1
LLM_MODEL=mimo-v2.5
LLM_TIMEOUT=30

# ========== 视觉模型 ==========
VISION_API_KEY=你的sk-开头的key
VISION_API_BASE=https://api.xiaomimimo.com/v1
VISION_MODEL=mimo-v2.5

# ========== 多轮对话 ==========
ENABLE_MULTI_TURN=1
MAX_HISTORY_TURNS=10

# ========== 历史问题缓存 ==========
ENABLE_QUESTION_CACHE=1
QA_SIMILARITY_THRESHOLD=0.999

# ========== HTTPS ==========
ENABLE_SSL=0

# ========== Redis ==========
ENABLE_REDIS=1
REDIS_HOST=host.docker.internal
REDIS_PORT=6379

# ========== Neo4j ==========
ENABLE_NEO4J=1
NEO4J_URI=bolt://host.docker.internal:7687
NEO4J_USER=neo4j
NEO4J_PASSWORD=neo4j123
NEO4J_TOP_K=5

# ========== MySQL（未启用） ==========
ENABLE_MYSQL=0

# ========== JWT（未启用） ==========
ENABLE_JWT=0

# ========== 屏蔽词（未启用） ==========
ENABLE_FILTER=0
```

## 六、Dockerfile 说明

```dockerfile
FROM python:3.9-slim

# 阿里云 apt 镜像（加速系统包下载）
RUN sed -i 's|http://deb.debian.org|http://mirrors.aliyun.com|g' /etc/apt/sources.list.d/debian.sources

# 阿里云 pip 镜像（加速 Python 包下载）
RUN pip config set global.index-url https://mirrors.aliyun.com/pypi/simple/ \
    && pip config set global.trusted-host mirrors.aliyun.com

# 系统依赖（faiss-cpu / build 需要）
RUN apt-get update && apt-get install -y --no-install-recommends \
        build-essential curl && \
    rm -rf /var/lib/apt/lists/*

# 先装 PyTorch CPU（避免被 pytorch 源的 jinja2 元数据冲突卡住）
RUN pip install --no-cache-dir torch --index-url https://download.pytorch.org/whl/cpu

# 安装其余 Python 依赖
COPY requirements.txt .
RUN pip install -r requirements.txt

# 复制项目代码
COPY core/ core/
COPY scripts/ scripts/
COPY templates/ templates/
COPY certs/ certs/
COPY static/ static/
COPY .env.docker .env

# 创建数据目录
RUN mkdir -p documents uploads vector_store/qa_history

EXPOSE 5000
CMD ["python", "scripts/app.py"]
```

## 九、常见问题

### Q1: 模型加载失败

报错：`FileNotFoundError: Path /app/models/m3e-base not found`

解决：确保 .env.docker 中模型路径为 `/models/m3e-base`（不是 `/app/models/`）

### Q2: Milvus 连接失败

报错：`Fail connecting to server on xxx:19530`

解决：确保 .env.docker 中 `MILVUS_HOST=host.docker.internal`

### Q3: Neo4j 认证失败

解决：清空数据卷重建

```bash
docker rm -f neo4j-rag
docker volume rm neo4j-rag-data
docker volume create neo4j-rag-data
docker run -d --name neo4j-rag -p 7474:7474 -p 7687:7687 -v neo4j-rag-data:/data -e NEO4J_AUTH=neo4j/neo4j123 neo4j:5-community
```

### Q4: 问问题报错 "请求失败"

检查 `docker logs gongdan10-app` 查看具体错误，常见原因：
- 模型路径不对
- Milvus 未连接
- LLM API Key 过期
