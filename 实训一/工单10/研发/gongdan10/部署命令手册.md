# gongdan10 RAG 项目 Docker 部署 — 完整命令行步骤

> 本项目在 WSL (Windows Subsystem for Linux) 中执行命令。
> 项目路径：`/mnt/d/桌面/gongdanzuoye/gongdan10`
> Windows 路径：`D:\桌面\gongdanzuoye\gongdan10`

---

## 第一步：确认现有环境

```bash
# 查看当前运行的容器（确认不影响已有服务）
docker ps --format "table {{.Names}}\t{{.Status}}\t{{.Ports}}"
```

预期看到：milvus-standalone、redis、attu-local、redisinsight 等已有服务正常运行。

---

## 第二步：进入项目目录

```bash
cd /mnt/d/桌面/gongdanzuoye/gongdan10
```

---

## 第三步：构建 Docker 镜像

```bash
docker build -t gongdan10-app .
```

> 首次构建约 15-20 分钟（下载 PyTorch CPU 175MB + Python 依赖）。
> 使用阿里云 apt/pip 镜像加速。
> 后续构建利用缓存约 2-3 分钟。

构建完成后验证：

```bash
docker images | grep gongdan10
```

预期输出：
```
gongdan10-app    latest    xxxxxxxx    About a minute ago    2.71GB
```

---

## 第四步：启动 Neo4j 知识图谱

```bash
# 停止并删除旧的 neo4j 容器（如有）
docker rm -f neo4j-rag 2>/dev/null

# 清空旧数据卷（首次部署可跳过）
docker volume rm neo4j-rag-data 2>/dev/null
docker volume create neo4j-rag-data

# 启动 Neo4j
docker run -d \
  --name neo4j-rag \
  -p 7474:7474 \
  -p 7687:7687 \
  -v neo4j-rag-data:/data \
  -e NEO4J_AUTH=neo4j/neo4j123 \
  neo4j:5-community
```

验证 Neo4j 启动：

```bash
docker ps --filter "name=neo4j-rag" --format "table {{.Names}}\t{{.Status}}"
```

预期输出：
```
neo4j-rag    Up 10 seconds
```

浏览器访问：http://localhost:7474
- 用户名：neo4j
- 密码：neo4j123

---

## 第五步：启动 RAG 应用

```bash
# 停止并删除旧的 app 容器（如有）
docker rm -f gongdan10-app 2>/dev/null

# 启动应用
docker run -d \
  --name gongdan10-app \
  -p 5000:5000 \
  -v /mnt/d/桌面/模型/:/models:ro \
  -v /mnt/d/桌面/gongdanzuoye/gongdan10/documents:/app/documents \
  -v /mnt/d/桌面/gongdanzuoye/gongdan10/uploads:/app/uploads \
  -v /mnt/d/桌面/gongdanzuoye/gongdan10/vector_store:/app/vector_store \
  --env-file /mnt/d/桌面/gongdanzuoye/gongdan10/.env.docker \
  --add-host=host.docker.internal:host-gateway \
  gongdan10-app
```

验证应用启动：

```bash
docker ps --filter "name=gongdan10-app" --format "table {{.Names}}\t{{.Status}}\t{{.Ports}}"
```

预期输出：
```
gongdan10-app    Up 5 seconds    0.0.0.0:5000->5000/tcp
```

## 日常操作命令

### 启动所有服务

```bash
docker start gongdan10-app neo4j-rag
```

### 停止所有服务

```bash
docker stop gongdan10-app neo4j-rag
```

### 重启应用（不重启 Neo4j）

```bash
docker restart gongdan10-app
```

### 重建应用（代码修改后）

```bash
# 1. 重新构建镜像
cd /mnt/d/桌面/gongdanzuoye/gongdan10
docker build -t gongdan10-app .

# 2. 重启容器
docker rm -f gongdan10-app
docker run -d \
  --name gongdan10-app \
  -p 5000:5000 \
  -v /mnt/d/桌面/模型/:/models:ro \
  -v /mnt/d/桌面/gongdanzuoye/gongdan10/documents:/app/documents \
  -v /mnt/d/桌面/gongdanzuoye/gongdan10/uploads:/app/uploads \
  -v /mnt/d/桌面/gongdanzuoye/gongdan10/vector_store:/app/vector_store \
  --env-file /mnt/d/桌面/gongdanzuoye/gongdan10/.env.docker \
  --add-host=host.docker.internal:host-gateway \
  gongdan10-app
```

### 添加新文档并重建索引

```bash
# 1. 把新文档放入 documents 目录
cp /path/to/new_document.pdf /mnt/d/桌面/gongdanzuoye/gongdan10/documents/

# 2. 重建索引
docker exec -it gongdan10-app python scripts/build_index.py
```

### 查看容器资源占用

```bash
docker stats gongdan10-app neo4j-rag --no-stream
```

### 查看所有 gongdan10 相关容器

```bash
docker ps -a --filter "name=gongdan10" --format "table {{.Names}}\t{{.Status}}\t{{.Ports}}"
```

### 进入容器调试

```bash
# 进入 app 容器
docker exec -it gongdan10-app bash

# 进入 neo4j 容器
docker exec -it neo4j-rag bash
```

### 清理所有 gongdan10 容器和镜像（完全卸载）

```bash
# 停止并删除容器
docker rm -f gongdan10-app neo4j-rag

# 删除镜像
docker rmi gongdan10-app

# 删除数据卷（可选，会丢失 neo4j 数据）
docker volume rm neo4j-rag-data
```

## 问题排查命令

### 应用启动失败

```bash
# 查看退出原因
docker ps -a --filter "name=gongdan10-app"
docker logs gongdan10-app
```

### Milvus 连不上

```bash
# 测试容器内能否访问 Milvus
docker exec gongdan10-app curl -s http://host.docker.internal:19530/v2/vectordb/collections/list
```

### Neo4j 连不上

```bash
# 测试容器内能否访问 Neo4j
docker exec gongdan10-app curl -s http://host.docker.internal:7687
```

### Redis 连不上

```bash
# 测试容器内能否访问 Redis
docker exec gongdan10-app python -c "import redis; r=redis.Redis(host='host.docker.internal',port=6379); print(r.ping())"
```

### 端口被占用

```bash
# 查看端口占用
ss -tlnp | grep 5000
ss -tlnp | grep 7474
ss -tlnp | grep 19530
ss -tlnp | grep 6379
```

### 清空 Neo4j 数据重置密码

```bash
docker rm -f neo4j-rag
docker volume rm neo4j-rag-data
docker volume create neo4j-rag-data
docker run -d \
  --name neo4j-rag \
  -p 7474:7474 \
  -p 7687:7687 \
  -v neo4j-rag-data:/data \
  -e NEO4J_AUTH=neo4j/neo4j123 \
  neo4j:5-community
```
