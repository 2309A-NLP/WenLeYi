# 招股书数据问答智能体 - 项目优点

## 一、技术架构优点

1. 公司名智能识别与过滤
   - 自动从问题中提取公司名，限定搜索范围到对应文档
   - 避免跨公司内容混淆，大幅提升检索准确率
   - 支持自动提取和手动补充两种方式，覆盖全部80家公司

2. 多层检索策略
   - 第一层：向量检索（m3e-base），快速筛选相关文本块
   - 第二层：公司名过滤，排除无关公司干扰
   - 第三层：Reranker精排（bge-reranker-base），进一步提升精度

3. 向量化存储
   - 使用Milvus向量数据库，支持高效相似度检索
   - 80份招股书切分为9801个文本块，全部向量化存储
   - 文本分块带重叠（500字），避免关键信息被切断

4. 大模型生成答案
   - 使用小米MiMo大模型生成自然语言回答
   - Prompt设计约束LLM从数据中提取答案，不编造信息
   - 自动去除markdown格式符号，输出干净文本

## 二、工程优点

1. 模块化设计
   - config.py：配置集中管理
   - company_mapping.py：公司名映射
   - build_index.py：索引构建
   - query.py：检索与生成
   - main.py：批量处理
   - web.py：网页前端

2. 容错与重试机制
   - API调用失败自动重试
   - 答案为空自动重试
   - 详细日志记录每一步处理过程

3. 前后端分离
   - Flask后端提供REST API
   - 纯HTML/CSS/JS前端，无需额外框架
   - 支持网页测试和批量处理两种模式

4. 全中文注释
   - 所有代码文件包含中文注释
   - 每个文件头部标注工单编号
   - 变量命名清晰，易于理解和维护

## 三、数据处理优点

1. 智能文本分块
   - 2048字符分块，500字重叠
   - 保证跨段落信息不丢失
   - 适配招股书正式文档的段落结构

2. 公司名提取鲁棒性
   - 处理字符间空格（"浙 江 双 飞"）
   - 处理字符重复（"杭杭州州州州"）
   - 处理截断文本（"股份有限"无"公司"结尾）
   - 支持前50000字符范围搜索

3. 问题筛选
   - 自动识别并过滤基金/股票类无关问题
   - 保留411道招股书相关问题
   - 输出文件干净，无无效答案

## 四、用户体验优点

1. 网页界面简洁直观
   - 对话式交互，输入问题即可获得答案
   - 预设示例问题，一键测试
   - 响应式设计，支持移动端

2. 批量处理能力
   - 支持一次处理全部411道问题
   - 输出标准JSONL格式，可直接提交
   - 处理进度实时显示

3. 灵活配置
   - 所有参数集中在config.py中
   - 模型、API、检索参数均可调整
   - 无需修改代码即可切换不同模型
