# 招股书数据问答智能体 - 部署过程

## 一、环境要求

| 组件 | 要求 |
|------|------|
| 操作系统 | Windows 10/11 |
| Python | 3.9（Anaconda） |
| 内存 | 8GB以上 |
| 磁盘空间 | 10GB以上 |
| Docker | 需要运行Milvus |

## 二、部署步骤

### 步骤1：启动Milvus向量数据库

Milvus通过Docker运行，确保Docker已启动：

```cmd
docker start milvus-docker-milvus-1 milvus-docker-etcd-1 milvus-docker-minio-1
```

验证Milvus是否正常运行：

```cmd
docker ps | findstr milvus
```

正常应看到三个容器：milvus-1、etcd-1、minio-1

### 步骤2：安装Python依赖

```cmd
cd /d D:\桌面\agent工单\agent工单5
pip install pymilvus==2.3.8
pip install sentence-transformers==2.2.2
pip install transformers==4.36.2
pip install huggingface_hub==0.20.3
pip install accelerate==0.24.1
pip install flask>=2.3.0
pip install requests>=2.28.0
```

注意：版本必须严格匹配，否则会出现兼容性问题。

### 步骤3：确认模型文件

确认本地模型文件存在：

```cmd
dir D:\桌面\模型\m3e-base
dir D:\桌面\模型\bge-reranker-base
```

模型文件应在上述目录中，不需要额外下载。

### 步骤4：构建向量索引

首次运行需要构建索引（约1.5小时）：

```cmd
cd /d D:\桌面\agent工单\agent工单5
python build_index.py
```

执行过程：
1. 读取80个TXT文件
2. 文本分块（2048字/块，500字重叠）
3. 用m3e-base向量化
4. 存入Milvus
5. 创建向量索引

看到"索引构建完成"表示成功。

### 步骤5：构建公司名映射

```cmd
python company_mapping.py
```

会自动提取80家公司的名称并建立映射。

### 步骤6：启动Web服务

```cmd
python web.py
```

浏览器打开 http://127.0.0.1:5005 即可使用。

### 步骤7：批量处理问题

生成最终答案文件：

```cmd
python main.py
```

输出文件：output/answer.jsonl

## 三、配置说明

所有配置在 config.py 中：

| 配置项 | 默认值 | 说明 |
|--------|--------|------|
| EMBEDDING_MODEL_PATH | D:\桌面\模型\m3e-base | 向量化模型路径 |
| RERANKER_MODEL_PATH | D:\桌面\模型\bge-reranker-base | 重排序模型路径 |
| MILVUS_HOST | 127.0.0.1 | Milvus地址 |
| MILVUS_PORT | 19530 | Milvus端口 |
| DEEPSEEK_API_KEY | 见config.py | API密钥 |
| DEEPSEEK_BASE_URL | https://api.xiaomimimo.com/v1 | API地址 |
| DEEPSEEK_MODEL | mimo-v2.5 | 模型名称 |
| CHUNK_SIZE | 2048 | 分块大小 |
| CHUNK_OVERLAP | 500 | 重叠大小 |
| SEARCH_TOP_K | 5 | 向量检索候选数 |
| MAX_TOKENS | 2048 | 最大生成token数 |

## 四、常见问题

| 问题 | 解决方案 |
|------|----------|
| Milvus连接失败 | 执行 docker start 启动容器 |
| 模型加载失败 | 检查模型路径，确认huggingface_hub版本为0.20.3 |
| API返回401 | 检查API Key和URL是否正确 |
| 答案为空 | 检查API余额，确认模型名称正确 |
| 内存不足 | 关闭其他程序，确保8GB以上可用内存 |
