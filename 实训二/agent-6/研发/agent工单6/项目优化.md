# 工单6 Agent编排器 — 项目优点

## 一、架构设计优点

### 1. Agent编排器模式
- 采用中心化编排架构，工单6作为统一入口
- 通过LLM（大语言模型）实现智能意图识别和参数提取
- 用户用自然语言输入，系统自动分发到对应工具服务

### 2. 微服务解耦
- 工单6本身是一个独立的Flask服务（端口8080）
- 通过HTTP调用与其他5个工单通信，互不依赖
- 某个工具服务故障不会影响工单6的正常运行

### 3. 统一代理层
- 前端通过代理路由访问各工具服务，避免跨域问题
- 代理支持GET/POST/PUT/DELETE全HTTP方法
- 代理超时配置120秒，兼容慢查询服务

## 二、功能优点

### 1. 多模态输入
- 纯文字对话：自然语言描述需求
- 图片上传：支持参考图片+文字描述混合输入
- 语音输入：浏览器Speech API语音识别
- 纯文字生图：豆包Seedream模型，无需参考图

### 2. 智能意图分发
- LLM自动识别用户意图（记账/日程/文生图/基金/招股书/闲聊）
- 自动提取工具调用所需参数
- 支持多工具同时调用（一次请求触发多个工具）

### 3. 双引擎文生图
- 豆包Seedream：纯文字描述直接生成图片（1920x1920）
- SiliconFlow Qwen：上传参考图片进行编辑
- 前端自动判断：有图走工单3编辑，无图走豆包生成

### 4. 基金/招股书智能问答
- 基金：LLM生成SQL → SQLite查询 → 格式化结果
- 招股书：向量检索 → Reranker重排序 → LLM生成答案
- 查询步骤进度提示：显示"生成SQL→查询→生成答案"

### 5. 记账详情展示
- 记账成功后显示完整记录信息（类型、日期、金额等）
- 不再只返回ID号，用户体验更友好

## 三、用户体验优点

### 1. 一体化操作界面
- 左侧边栏：5个工具入口 + 在线状态指示灯
- 顶部导航：实时显示服务健康状态（绿灯/红灯）
- 工具页面：iframe嵌入，无需跳转新页面

### 2. 交互细节
- 图片上传预览：发送前可预览、可移除、可点击放大
- 生成图片展示：大图查看、下载、灯箱效果
- 停止按钮：随时中断正在进行的请求
- 快捷按钮：一键发送常用查询（底部tip栏）
- 每次打开全新对话：不保留历史消息

### 3. 错误处理友好
- API调用失败：显示具体错误原因
- 服务离线：红色指示灯 + 友好提示
- 请求中断：显示"已停止生成"

## 四、技术优点

### 1. 性能优化
- HTTP超时120秒：兼容基金/招股书的慢查询
- 图片代理转发：解决豆包API的CORS跨域问题
- 健康检查兼容：支持返回JSON或HTML的服务

### 2. 容错机制
- 工具服务健康检查：每30秒自动检测
- LLM调用失败：返回友好提示而非技术错误
- 图片生成失败：显示错误原因便于排查

### 3. 可扩展性
- 新增工具：添加Flask服务 → 更新config.py → 更新Prompt
- 支持多LLM：可切换DeepSeek、小米MiMo等
- 工具服务可独立部署和扩展
