# 工单6 Agent编排器 — 项目思维导图

```
工单6 Agent编排器
│
├── 1. 核心架构
│   ├── Flask Web服务（端口8080）
│   ├── LLM意图识别引擎（小米MiMo）
│   ├── 工具服务代理层
│   └── 统一前端界面
│
├── 2. 文件结构
│   ├── app.py              主程序（路由+API+豆包文生图）
│   ├── orchestrator.py     编排器（意图识别+工具分发+结果格式化）
│   ├── tool_client.py      工具客户端（HTTP调用+健康检查）
│   ├── config.py           配置管理（工具地址+LLM+超时）
│   ├── templates/
│   │   └── index.html      前端界面（HTML+CSS+JS，2300+行）
│   ├── .env                环境变量（API Key+服务地址）
│   └── requirements.txt    Python依赖
│
├── 3. 功能模块
│   ├── 对话模块
│   │   ├── /chat 接口
│   │   ├── LLM意图识别（记账/日程/文生图/基金/招股书/闲聊）
│   │   ├── 参数提取
│   │   └── 结果格式化
│   │
│   ├── 文字生图模块
│   │   ├── /api/text2img 接口
│   │   ├── 豆包Seedream API（ep-20260629111310-268wr）
│   │   ├── 前端正则匹配触发
│   │   └── 图片URL返回+显示
│   │
│   ├── 图片上传模块
│   │   ├── 🖼️上传按钮+预览条
│   │   ├── FileReader读取base64
│   │   ├── 用户气泡显示原图
│   │   └── 调用工单3图片编辑API
│   │
│   ├── 健康检查模块
│   │   ├── /health 接口
│   │   ├── 30秒定时轮询
│   │   ├── 兼容JSON/HTML响应
│   │   └── 侧边栏+顶部状态灯
│   │
│   └── 请求控制模块
│       ├── ⏹停止按钮
│       ├── AbortController中断
│       └── 步骤进度提示
│
├── 4. 工具调用链路
│   ├── 记账（端口5001）
│   │   ├── POST /api/v1/record/add
│   │   ├── GET /api/v1/record/query
│   │   ├── POST /api/v1/record/delete
│   │   └── POST /api/v1/record/update
│   │
│   ├── 日程（端口5002）
│   │   ├── POST /api/v1/schedule/add
│   │   ├── GET /api/v1/schedule/query
│   │   ├── POST /api/v1/schedule/delete
│   │   └── POST /api/v1/schedule/update
│   │
│   ├── 文生图（端口5003）
│   │   ├── POST /api/v1/image/generate
│   │   └── POST /api/v1/image/generate_all
│   │
│   ├── 基金（端口5000）
│   │   └── POST /api/ask
│   │
│   └── 招股书（端口5005）
│       └── POST /api/v1/prospectus/query
│
├── 5. 前端技术
│   ├── 布局
│   │   ├── 左侧边栏（工具导航+状态灯）
│   │   ├── 顶部导航栏（标题+工具状态+操作按钮）
│   │   ├── 聊天区域（消息列表+欢迎页）
│   │   ├── 输入区域（文本框+上传+语音+发送+停止）
│   │   └── 工具页面（iframe嵌入）
│   │
│   ├── 样式
│   │   ├── 深色主题（CSS变量）
│   │   ├── 响应式布局（移动端适配）
│   │   ├── 动画效果（fadeInUp+hover）
│   │   └── 灯箱/弹窗组件
│   │
│   └── 交互
│       ├── 发送消息（fetch API）
│       ├── 图片上传（FileReader）
│       ├── 语音识别（SpeechRecognition）
│       ├── 请求中断（AbortController）
│       └── 工具切换（iframe加载）
│
└── 6. 配置管理
    ├── .env 环境变量
    │   ├── LLM_API_KEY（小米MiMo密钥）
    │   ├── LLM_BASE_URL（API地址）
    │   ├── LLM_MODEL（模型名）
    │   ├── TOOL_*_URL（各工具服务地址）
    │   ├── FLASK_PORT（8080）
    │   └── HTTP_TIMEOUT（120秒）
    │
    └── config.py 代码配置
        ├── TOOL_SERVICES（工具服务定义）
        ├── TOOL_PROXY_MAP（代理路由映射）
        ├── FLASK_HOST/PORT/DEBUG
        └── HTTP_TIMEOUT
```
