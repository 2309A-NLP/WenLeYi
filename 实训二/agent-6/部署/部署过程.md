# 工单6 Agent编排器 — 部署过程

## 一、环境要求

### 1. 运行环境
| 软件 | 版本 | 用途 |
|------|------|------|
| Python | 3.9+ | 运行环境 |
| Flask | 2.3+ | Web框架 |
| flask-cors | 4.0+ | 跨域支持 |
| requests | 2.28+ | HTTP请求 |
| python-dotenv | 1.0+ | 环境变量管理 |

### 2. 前置依赖（需先启动）
- 工单1 记账本（端口5001）+ MySQL
- 工单2 日程提醒（端口5002）+ MySQL
- 工单3 文生图（端口5003）+ SiliconFlow API
- 工单4 基金问答（端口5000）+ SQLite + Milvus
- 工单5 招股书问答（端口5005）+ Milvus

## 二、部署步骤

### 第一步：安装Python依赖
```cmd
cd /d D:\桌面\agent工单\agent工单6
pip install -r requirements.txt
```

### 第二步：配置环境变量
编辑 `.env` 文件：
```env
# LLM配置（小米MiMo）
LLM_API_KEY=你的MiMo密钥
LLM_BASE_URL=https://api.xiaomimimo.com/v1
LLM_MODEL=mimo-v2.5

# 豆包文生图（内置API Key，无需修改）
DOUBAO_API_KEY=*****

# 工具服务地址（默认配置，按需修改）
TOOL_ACCOUNTING_URL=http://127.0.0.1:5001
TOOL_SCHEDULE_URL=http://127.0.0.1:5002
TOOL_IMAGE_URL=http://127.0.0.1:5003
TOOL_FUND_URL=http://127.0.0.1:5000
TOOL_PROSPECTUS_URL=http://127.0.0.1:5005

# Flask配置
FLASK_HOST=0.0.0.0
FLASK_PORT=8080
FLASK_DEBUG=true
HTTP_TIMEOUT=120
```

### 第三步：启动工单6
```cmd
cd /d D:\桌面\agent工单\agent工单6
python app.py
```

### 第四步：验证启动
```
浏览器打开：http://localhost:8080
```
- 左侧边栏显示5个工具入口
- 绿色指示灯表示对应服务在线
- 红色表示对应服务未启动

## 四、核心文件说明

| 文件 | 功能 |
|------|------|
| app.py | Flask主程序，定义所有路由和API接口 |
| orchestrator.py | 编排器核心，LLM意图识别+工具分发 |
| tool_client.py | 工具服务HTTP客户端，封装所有工具调用 |
| config.py | 配置管理，工具服务地址+LLM配置 |
| templates/index.html | 前端界面（HTML+CSS+JS） |
| .env | 环境变量配置文件 |

## 五、API接口列表

### 对话接口
```
POST /chat
请求: {"message": "用户输入", "session_id": "会话ID"}
响应: {"reply": "回复文本", "tool_used": "使用的工具"}
```

### 文字生图
```
POST /api/text2img
请求: {"prompt": "图片描述"}
响应: {"code": 0, "data": {"image_url": "图片URL"}}
```

### 健康检查
```
GET /health
响应: {"code": 0, "data": {"services": {"记账": true, ...}}}
```

### 工具代理
```
POST /api/proxy/{工具名}/{接口路径}
直接转发到对应的工具服务
```

## 六、常见问题

### 问题1：端口8000被占用
```cmd
netstat -ano | findstr :8080
taskkill /F /PID <进程ID>
```

### 问题2：LLM返回401 Unauthorized
- 检查 .env 中的 LLM_API_KEY 是否有效
- 检查 LLM_BASE_URL 是否正确

### 问题3：基金问答返回空
- 确认工单4（端口5000）已启动
- 确认 .env 中 TOOL_FUND_URL 指向正确端口

### 问题4：文生图返回400
- 确认工单3（端口5003）已启动
- 检查SiliconFlow API Key是否有效
- 豆包生图检查接入点ID是否正确

### 问题5：服务状态显示红色
- 确认对应工单服务已启动
- 检查 .env 中的服务地址端口是否正确
- 点击刷新按钮重新检测

## 七、停止服务
```cmd
# 方式1：关闭工单6的CMD窗口
# 方式2：在CMD中执行
taskkill /F /IM python.exe /T
```
