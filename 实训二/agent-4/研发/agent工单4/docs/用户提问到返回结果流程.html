用户提问到返回结果 - 完整流程

一、整体流程图

用户在网页输入问题 ↓ Flask接收HTTP请求 ↓ 判断问题类型 ┌─────┴─────┐ ↓ ↓ 数据库问题 招股书问题 ↓ ↓ 构建Prompt 搜索PDF文件 ↓ ↓ 调用DeepSeek 提取相关内容 ↓ ↓ 生成SQL 调用DeepSeek ↓ ↓ 执行SQL 生成答案 ↓ ↓ 格式化答案 格式化答案 ↓ ↓ └─────┬─────┘ ↓ 返回JSON给前端 ↓ 网页显示答案

二、详细步骤分解

步骤1：用户输入问题

用户在网页界面输入自然语言问题，点击"查询"按钮

用户输入: "20210331持有贵州茅台最多的基金是哪个" 点击按钮 → 触发JavaScript函数 askQuestion()
↓
步骤2：前端发送请求

JavaScript将问题通过HTTP POST发送到后端API

fetch('/api/ask', { method: 'POST', headers: {'Content-Type': 'application/json'}, body: JSON.stringify({question: '20210331持有贵州茅台最多的基金是哪个'}) })
↓
步骤3：Flask接收请求

web.py中的路由函数接收问题，调用ask()函数

@app.route('/api/ask', methods=['POST']) def api_ask(): data = request.get_json() question = data.get('question', '') result = ask(question) # 核心处理函数 return jsonify(result)
↓
步骤4：问题分类

系统判断问题类型，决定走哪条处理路径

from prompt_builder import is_prospectus_question if is_prospectus_question(question): # 招股书问题 → PDF解析流程 else: # 数据库问题 → NL2SQL流程
判断依据：检查问题是否包含"招股"、"法定代表人"、"发起人"等关键词
↓

三、数据库问题处理流程（NL2SQL）

步骤5a：构建Prompt

将数据库Schema、规则、示例组合成完整的System Prompt

System Prompt 内容: ┌─────────────────────────────────────┐ │ 1. 角色定义: 你是基金数据SQL专家 │ │ 2. 数据库Schema: 10张表的字段信息 │ │ 3. 表关联关系: 基金代码、股票代码 │ │ 4. 重要规则: 字段名必须匹配 │ │ 5. 9个示例: 各类问题的SQL写法 │ └─────────────────────────────────────┘ User Prompt: 问题: 20210331持有贵州茅台最多的基金是哪个? SQL:
↓
步骤6a：调用DeepSeek API

将Prompt发送给DeepSeek，获取生成的SQL

请求: POST https://api.deepseek.com/chat/completions { "model": "deepseek-chat", "messages": [ {"role": "system", "content": "System Prompt..."}, {"role": "user", "content": "问题: 20210331持有贵州茅台最多的基金是哪个?\n\nSQL:"} ], "temperature": 0.1 } 响应: SELECT 基金简称,数量 FROM 基金股票持仓明细 WHERE 股票名称='贵州茅台' AND 持仓日期='20210331' ORDER BY 数量 DESC LIMIT 1
↓
步骤7a：执行SQL查询

在SQLite数据库上执行SQL（30秒超时）

数据库: 博金杯比赛数据.db (1.46GB) 执行: SELECT 基金简称,数量 FROM 基金股票持仓明细 WHERE 股票名称='贵州茅台' AND 持仓日期='20210331' ORDER BY 数量 DESC LIMIT 1 结果: [('鹏华匠心精选混合C', 1062620)]
↓
步骤8a：格式化答案

将查询结果格式化为用户可读的答案

格式化规则: - 单行单列: 直接返回值 - 单行多列: 字段名:值 格式 - 多行: 分点编号显示 - 自动去重 - 数值精度处理 结果: 基金简称: 鹏华匠心精选混合C, 数量: 1062620

四、招股书问题处理流程（PDF解析）

步骤5b：提取公司名

从问题中用正则表达式提取公司名称

问题: "华瑞电器股份有限公司的法定代表人是谁" 正则: ([\u4e00-\u9fa5]{2,20}(?:有限公司|股份有限公司)) 提取: 华瑞电器股份有限公司
↓
步骤6b：查找PDF文件

在80个txt文件中搜索对应的公司

搜索方式: 1. 精确匹配公司名 → 未找到 2. 模糊匹配（包含关系）→ 未找到 3. grep搜索文件内容 → 找到 3e0ded8a...txt
↓
步骤7b：提取相关内容

根据问题关键词，在文件中搜索相关段落

关键词: ["法定代表人", "代表人", "董事长"] 搜索: 逐行扫描，找包含关键词的行 上下文: 前后各3行 结果: 公司住所： 宁波市鄞州区姜山镇科技园区 成立日期： 1996年2月12日 法定代表人： 孙瑞良 ← 找到了！ 注册资本： 7,500万元
↓
步骤8b：调用DeepSeek生成答案

将提取的内容发给DeepSeek，让它生成答案

System: 你是金融文档分析专家，根据内容回答问题 User: 招股书内容: [提取的段落] 问题: 华瑞电器股份有限公司的法定代表人是谁 答案: 响应: 孙瑞良

五、返回结果

步骤9：返回JSON给前端

将答案封装成JSON格式返回

返回格式: { "question": "20210331持有贵州茅台最多的基金是哪个", "answer": "基金简称: 鹏华匠心精选混合C, 数量: 1062620", "sql": "SELECT 基金简称,数量 FROM 基金股票持仓明细 WHERE...", "error": null }
↓
步骤10：前端显示答案

JavaScript解析JSON，在网页上显示答案

chatBox.innerHTML += `
系统
基金简称: 鹏华匠心精选混合C, 数量: 1062620
`; chatBox.scrollTop = chatBox.scrollHeight; // 自动滚动
