一、文档解析流程（PDF招股书）

步骤1：用户输入问题

"华瑞电器股份有限公司的法定代表人是谁"
↓

步骤2：识别公司名

用正则表达式从问题中提取公司名称：

正则: ([\u4e00-\u9fa5]{2,20}(?:有限公司|股份有限公司)) 提取: 华瑞电器股份有限公司
↓

步骤3：查找PDF文件

在pdf_txt_file目录的80个txt文件中搜索：

方法1: 精确匹配公司名 → 未找到 方法2: 模糊匹配（包含关系）→ 未找到 方法3: grep搜索文件内容 → 找到 3e0ded8a...txt
↓

步骤4：提取相关内容

根据问题关键词，在文件中搜索相关段落：

关键词: ["法定代表人", "代表人", "董事长", "总经理"] 搜索: 逐行扫描，找到包含关键词的行 结果: 公司住所： 宁波市鄞州区姜山镇科技园区 成立日期： 1996年2月12日 法定代表人： 孙瑞良 ← 找到了！ 注册资本： 7,500万元
↓

步骤5：调用LLM生成答案

把提取的内容发给DeepSeek：

System: 你是金融文档分析专家，根据内容回答问题 User: 招股书内容: [提取的段落] 问题: 华瑞电器股份有限公司的法定代表人是谁 答案: → DeepSeek返回: 孙瑞良
↓

最终答案

答案: 孙瑞良

二、数据库检索流程（NL2SQL）

步骤1：用户输入问题

"20210331持有贵州茅台最多的基金是哪个"
↓

步骤2：构建Prompt

包含数据库Schema、规则、Few-shot示例：

System Prompt: 数据库有10张表: - 基金基本信息(基金代码,基金简称,管理人,...) - 基金股票持仓明细(基金代码,股票名称,数量,...) - ... 规则: 1. 只返回SQL 2. 日期用YYYYMMDD 3. 字段含括号用双引号 示例: Q: 基金000006的名称是什么? S: SELECT 基金简称 FROM 基金基本信息 WHERE 基金代码='000006' User Prompt: 问题: 20210331持有贵州茅台最多的基金是哪个? SQL:
↓

步骤3：调用DeepSeek生成SQL

LLM理解问题后生成SQL：

输入: [完整Prompt] 输出: SELECT 基金简称, 数量 FROM 基金股票持仓明细 WHERE 股票名称='贵州茅台' AND 持仓日期='20210331' ORDER BY 数量 DESC LIMIT 1
↓

步骤4：执行SQL查询

在SQLite数据库上执行（30秒超时）：

数据库: 博金杯比赛数据.db 执行: SELECT 基金简称, 数量 FROM 基金股票持仓明细 WHERE 股票名称='贵州茅台' AND 持仓日期='20210331' ORDER BY 数量 DESC LIMIT 1 耗时: 0.3秒 结果: [('鹏华匠心精选混合C', 1062620)]
↓

最终答案

答案: 鹏华匠心精选混合C，持有1062620股
