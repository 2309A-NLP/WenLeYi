基金数据问答系统 - 详细技术文档

一、系统架构概述

本系统采用 NL2SQL（Natural Language to SQL） 架构，核心思路是：

用户问题 → LLM翻译 → SQL查询 → 数据库返回答案

不是RAG系统，没有文档分块、向量检索、答案拼接等环节。

不是关键词检索，不依赖关键词匹配。

核心是LLM理解语义后生成SQL，由SQL直接查询数据库获取答案。

二、详细流程分解

步骤1：用户输入问题

用户输入自然语言问题，例如：

"20210331持有贵州茅台最多的基金是哪个"

步骤2：问题分类

系统通过关键词匹配判断问题复杂度：

# 简单问题：直接用DeepSeek "基金000006的名称是什么" → 简单 # 复杂问题：也用DeepSeek（暂未区分模型） "涨跌幅最大的股票" → 复杂

判断依据：问题是否包含"涨跌幅"、"排名"、"合计"、"行业"等关键词

步骤3：构建Prompt（关键步骤）

系统构建一个包含以下内容的Prompt发给DeepSeek：

3.1 数据库Schema（表结构）

数据库有10张表： - 基金基本信息(基金代码,基金简称,管理人,托管人,基金类型,成立日期,管理费率,托管费率) - 基金日行情表(基金代码,交易日期,单位净值,复权单位净值,累计单位净值,资产净值) - A股票日行情表(股票代码,交易日,"昨收盘(元)","今开盘(元)","最高价(元)","最低价(元)","收盘价(元)","成交量(股)","成交金额(元)") - A股公司行业划分表(股票代码,交易日期,行业划分标准,一级行业名称,二级行业名称) - 基金股票持仓明细(基金代码,基金简称,持仓日期,股票代码,股票名称,数量,市值,市值占基金资产净值比,第N大重仓股,报告类型) ... (共10张表)

3.2 表关联关系

关联: 基金基本信息.基金代码→各基金表 基金股票持仓明细.股票代码→A股票日行情表/A股公司行业划分表

3.3 生成规则

规则: 1. 只返回SQL，无解释 2. 日期用YYYYMMDD字符串比较 3. 涨跌幅=(收盘价-昨收盘)/昨收盘*100% 4. A股票日行情表字段必须用双引号 5. 涨停:收盘价/昨收盘-1>=0.098

3.4 Few-shot示例（从Milvus检索）

示例: Q:基金000006的名称是什么? S:SELECT 基金简称 FROM 基金基本信息 WHERE 基金代码='000006' Q:20210331持有贵州茅台最多的基金? S:SELECT 基金简称,数量 FROM 基金股票持仓明细 WHERE 股票名称='贵州茅台' AND 持仓日期='20210331' ORDER BY 数量 DESC LIMIT 1

步骤4：调用DeepSeek API生成SQL

将上述Prompt发送给DeepSeek API，LLM返回SQL：

输入: [完整的System Prompt + 用户问题] 输出: SELECT 基金简称, 数量 FROM 基金股票持仓明细 WHERE 股票名称='贵州茅台' AND 持仓日期='20210331' ORDER BY 数量 DESC LIMIT 1
关键技术：LLM理解了用户意图，知道需要：
  • 查"基金股票持仓明细"表
  • 筛选股票名称='贵州茅台'
  • 筛选持仓日期='20210331'
  • 按数量降序排列
  • 只取第一条（最多的）

步骤5：执行SQL查询

在SQLite数据库上执行SQL（30秒超时）：

数据库: 博金杯比赛数据.db (1.46GB) 执行: SELECT 基金简称, 数量 FROM 基金股票持仓明细 WHERE 股票名称='贵州茅台' AND 持仓日期='20210331' ORDER BY 数量 DESC LIMIT 1 耗时: 0.3秒（有索引） 结果: [('鹏华匠心精选混合C', 1062620)]

步骤6：格式化答案

根据结果类型格式化：

# 单条单列：直接显示 结果: [('鹏华匠心精选混合C',)] 答案: 鹏华匠心精选混合C # 单条多列：字段名:值 结果: [('鹏华匠心精选混合C', 1062620)] 答案: 基金简称: 鹏华匠心精选混合C, 数量: 1062620 # 多条：分点编号 结果: [('A', 100), ('B', 80), ('C', 50)] 答案: 1. 基金A | 数量: 100 2. 基金B | 数量: 80 3. 基金C | 数量: 50

步骤7：返回答案

在网页上显示最终答案：

答案: 鹏华匠心精选混合C

三、错误处理机制

SQL执行失败时的重试流程：

SQL执行报错 → 把错误信息反馈给LLM → LLM修正SQL → 重新执行
# 第一次生成的SQL SELECT 收盘价 FROM A股票日行情表 WHERE ... 错误: no such column: 收盘价 # 反馈给LLM后修正 SELECT "收盘价(元)" FROM A股票日行情表 WHERE ... 成功 ✓

最多重试2次，如果还是失败则返回错误信息。

四、关键技术总结

环节 技术 说明
问题理解 LLM语义理解 DeepSeek理解自然语言意图
SQL生成 NL2SQL LLM将问题翻译成SQL语句
数据存储 SQLite 1.46GB结构化数据库
索引优化 B-Tree索引 加速查询，从十几秒到零点几秒
Few-shot示例 Milvus向量检索 动态找最相似的已知Q-SQL对
Embedding m3e-base 把问题转向量，用于相似度搜索

五、与其他方案的区别

方案 本系统(NL2SQL) RAG系统
数据源 结构化数据库 非结构化文档
检索方式 SQL查询 向量相似度搜索
分块 不需要 需要文档分块
答案来源 数据库精确查询 检索文档片段+LLM生成
准确性 100%精确（如果SQL正确） 可能有幻觉
