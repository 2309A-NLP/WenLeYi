## 关联关系

```
基金基本信息 (基金代码)
    ├── 基金日行情表 (基金代码)
    ├── 基金股票持仓明细 (基金代码)
    │       └── A股票日行情表 (股票代码)
    │       └── A股公司行业划分表 (股票代码)
    ├── 基金债券持仓明细 (基金代码)
    ├── 基金可转债持仓明细 (基金代码)
    │       └── A股票日行情表 (对应股票代码)
    ├── 基金规模变动表 (基金代码)
    └── 基金份额持有人结构 (基金代码)

A股票日行情表 (股票代码)
    └── A股公司行业划分表 (股票代码)
```

## 注意事项

1. **日期格式不一致**：
   - 基金日行情表/A股票日行情表/港股票日行情表/A股公司行业划分表/持仓明细表：YYYYMMDD
   - 基金规模变动表/基金份额持有人结构：YYYY-MM-DD HH:MM:SS

2. **涨跌幅计算公式**（来自题目）：
   - 股票涨跌幅 = (收盘价 - 前一日收盘价) / 前一日收盘价 * 100%

3. **行业划分标准**：A股公司行业划分表中有多个行业划分标准（如中信行业分类）

4. **报告类型**：持仓表和规模变动表中有年报、半年报、季报等不同报告类型
