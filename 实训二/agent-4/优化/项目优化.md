# 基金数据问答系统 - 项目优点

## 一、技术创新

### 1. NL2SQL技术应用
- 采用业界主流的NL2SQL（自然语言转SQL）技术
- 将自然语言问题自动转换为精确的SQL查询
- 答案100%来自数据库，无幻觉问题

### 2. 多模型架构
- 支持DeepSeek、小米mimo等多种LLM
- 可根据模型表现灵活切换
- 预留多模型分发接口

### 3. 动态Few-shot检索
- 集成Milvus向量数据库
- 基于m3e-base的中文Embedding模型
- 动态检索最相似的历史问答对

### 4. 招股书PDF解析
- 支持PDF文本提取
- 从80份招股书中检索相关信息

---

## 二、技术架构

### 1. 模块化设计
- 9个独立Python模块，职责清晰
- 便于维护、测试和扩展

### 2. 前后端分离
- Flask后端 + HTML/CSS/JS前端
- RESTful API设计

### 3. 容错机制
- SQL执行超时保护（60秒）
- API调用失败自动重试
- 错误日志记录

### 4. 性能优化
- 数据库索引优化（7个索引）
- Prompt精简（2004字符）
- 结果自动去重
