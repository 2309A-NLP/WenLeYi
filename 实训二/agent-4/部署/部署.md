# 基金数据问答系统 - 部署过程

## 一、环境准备

### 1. Python环境
- Python 3.9+
- 推荐使用Anaconda创建虚拟环境

### 2. 安装依赖
```
pip install flask requests pymupdf sentence-transformers
```

### 3. 数据准备
```
# 下载数据集
git clone https://www.modelscope.cn/datasets/BJQW14B/bs_challenge_financial_14b_dataset.git

# 复制文件到项目目录
- 博金杯比赛数据.db（1.46GB）
- question.json（1000道题）
- pdf/ 目录（80份招股书）
- pdf_txt_file/ 目录（80个txt文件）
```

### 4. 模型准备
- 下载m3e-base模型到本地（用于Embedding）
- 配置DeepSeek API Key

---

## 二、数据库优化

### 创建索引（加速查询）
```sql
CREATE INDEX idx_industry_name ON A股公司行业划分表(一级行业名称);
CREATE INDEX idx_industry_std ON A股公司行业划分表(行业划分标准);
CREATE INDEX idx_stock_code ON A股票日行情表(股票代码);
CREATE INDEX idx_fund_code ON 基金基本信息(基金代码);
CREATE INDEX idx_fund_daily ON 基金日行情表(基金代码);
CREATE INDEX idx_hold_code ON 基金股票持仓明细(基金代码);
CREATE INDEX idx_hold_name ON 基金股票持仓明细(股票名称);
```

## 六、常见问题

### 1. API调用失败
- 检查网络连接
- 检查API Key是否有效

### 2. 查询超时
- 检查是否缺少索引
- 适当增加SQL_TIMEOUT

### 3. Embedding模型加载失败
- 检查模型路径是否正确
- 检查huggingface_hub版本
