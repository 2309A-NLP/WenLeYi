# 文生图智能体 - 部署文档

## 一、环境要求

### 1.1 硬件要求
- 操作系统：Windows 10/11、Linux、macOS
- 内存：4GB以上
- 硬盘：500MB可用空间
- 网络：需要互联网连接（调用云端API）

### 1.2 软件要求
- Python 3.9 或更高版本
- pip 包管理器
- 现代浏览器（Chrome、Firefox、Edge）

---

## 二、安装步骤

### 2.1 获取项目文件

将项目文件夹 `agent工单3` 复制到本地目录，例如：
```
D:\桌面\agent工单\agent工单3
```

项目文件结构：
```
agent工单3/
├── app.py                 # 后端主程序
├── templates/
│   └── index.html         # 前端页面
├── output/                # 生成图片目录（自动创建）
├── requirements.txt       # Python依赖
├── 设计文档.md
├── 过程记录.md
├── 项目优点.md
├── 思维导图.html
└── 部署文档.md
```

### 2.2 安装Python依赖

打开命令行（CMD或PowerShell），执行：

```bash
# 进入项目目录
cd D:\桌面\agent工单\agent工单3

# 安装依赖包
pip install -r requirements.txt
```

如果没有requirements.txt或安装失败，可手动安装：

```bash
pip install flask requests Pillow
```

### 2.3 配置API Key

#### 方式一：修改代码（推荐）
编辑 `app.py` 文件，找到以下行：

```python
QWEN_API_KEY = "你的API密钥"
```

替换为你的硅基流动API Key。

#### 方式二：环境变量（更安全）
设置环境变量 `QWEN_API_KEY`，代码会自动读取。

### 2.4 获取硅基流动API Key

1. 访问 https://cloud.siliconflow.cn 注册账号
2. 登录后进入控制台
3. 点击"API密钥"菜单
4. 点击"创建密钥"
5. 复制生成的API Key（格式：sk-xxxxx）

**注意**：新用户有免费额度，注意使用量。

## 四、使用说明

### 4.1 上传参考图片
- **方式一**：点击上传框，选择图片文件
- **方式二**：拖拽图片文件到上传框

支持的图片格式：JPG、PNG、GIF、BMP

### 4.2 生成单张图片
1. 点击方向按钮（右转30°/正面/左转30°）
2. 提示词会自动填充到文本框
3. 点击"生成图片"按钮
4. 等待生成完成（约10-30秒）
5. 生成的图片会显示在右侧结果区

### 4.3 批量生成三张
1. 上传参考图片
2. 点击"一键生成三张（左+正+右）"按钮
3. 等待三张图片依次生成
4. 每张图片都有独立的下载按钮

### 4.4 下载图片
- 生成完成后，点击图片下方的"下载图片"按钮
- 图片会保存到浏览器默认下载目录

## 五、常见问题

### 5.1 启动失败

**问题**：`python: command not found`
**解决**：
- 确认Python已安装：`python --version`
- 确认Python已添加到系统PATH
- 尝试使用 `python3` 命令

### 5.2 依赖安装失败

**问题**：`pip install` 报错
**解决**：
```bash
# 使用国内镜像源
pip install -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple
```

### 5.3 API调用失败

**问题**：`401 Unauthorized` 或 `400 Bad Request`
**解决**：
- 检查API Key是否正确
- 检查网络连接
- 确认硅基流动账号有余额

### 5.4 生成效果不好

**问题**：生成的图片与原图差异大
**解决**：
- 使用清晰的参考图片（建议512x512以上）
- 使用正面人脸图片效果最佳
- 避免使用侧脸或遮挡严重的图片

### 5.5 端口被占用

**问题**：`Address already in use`
**解决**：
```bash
# 修改app.py中的端口号
app.run(debug=True, host="0.0.0.0", port=5001)
```

## 六、生产环境部署

### 6.1 使用Gunicorn（Linux/Mac）

```bash
# 安装gunicorn
pip install gunicorn

# 启动服务（4个worker）
gunicorn -w 4 -b 0.0.0.0:5000 app:app
```

### 6.2 使用Waitress（Windows）

```bash
# 安装waitress
pip install waitress

# 创建启动脚本
```

创建 `start_server.py`：
```python
from waitress import serve
from app import app

print("文生图智能体启动中...")
print("访问地址: http://localhost:5000")
serve(app, host="0.0.0.0", port=5000)
```

运行：
```bash
python start_server.py
```

### 6.3 使用Docker（可选）

创建 `Dockerfile`：
```dockerfile
FROM python:3.9-slim

WORKDIR /app

COPY requirements.txt .
RUN pip install -r requirements.txt

COPY . .

EXPOSE 5000

CMD ["python", "app.py"]
```

构建和运行：
```bash
docker build -t face-generator .
docker run -p 5000:5000 face-generator
```

## 七、安全注意事项

### 7.1 API Key保护
- 不要将API Key提交到代码仓库
- 使用环境变量存储敏感信息
- 定期更换API Key

### 7.2 网络安全
- 生产环境建议使用HTTPS
- 配置防火墙规则
- 限制访问IP（如需要）

### 7.3 数据安全
- 生成的图片及时清理
- 不存储用户上传的原始图片
- 遵守数据隐私法规

## 八、性能优化

### 8.1 图片大小
- 上传图片建议小于5MB
- 过大的图片会增加处理时间

### 8.2 并发控制
- 批量生成时是串行处理
- 避免同时发起多个批量请求

### 8.3 缓存策略
- 生成的图片URL有24小时有效期
- 可以考虑本地缓存常用图片
