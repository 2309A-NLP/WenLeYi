## 二、部署步骤

### 2.1 获取项目文件

将以下文件复制到目标目录 `D:\桌面\agent工单\agent工单2\`：

```
agent工单2/
├── config.py              # 配置文件
├── database.py            # 数据库操作
├── agent.py               # LLM对话核心
├── scheduler.py           # 精确提醒调度
├── app.py                 # Flask主程序
├── templates/
│   └── index.html         # 前端页面
├── 项目优点文档.md
├── 思维导图.md
├── 验收文档.md
└── 部署文档.md
```

### 2.2 安装Python依赖

打开命令行（CMD或Anaconda Prompt），执行：

```bash
pip install flask pymysql requests apscheduler python-dateutil
```

如使用Anaconda环境：

```bash
conda activate nlp_1
pip install flask pymysql requests apscheduler python-dateutil
```

### 2.3 配置数据库连接

编辑 `config.py`，修改数据库连接信息：

```python
# MySQL 数据库配置
DB_HOST = "172.22.224.1"      # MySQL地址
DB_PORT = 3306                 # MySQL端口
DB_USER = "root"               # 用户名
DB_PASSWORD = "*******"        # 密码（文档中用*******代替）
DB_NAME = "accounting_db"      # 数据库名
DB_CHARSET = "utf8mb4"         # 字符集
```

### 2.4 配置DeepSeek API

编辑 `config.py`，修改API Key：

```python
# DeepSeek API 配置
DEEPSEEK_API_KEY = "sk-*******"    # API Key（文档中用*******代替）
DEEPSEEK_BASE_URL = "https://api.deepseek.com/v1"
DEEPSEEK_MODEL = "deepseek-chat"
```

### 2.5 初始化数据库

执行以下命令自动创建数据表：

```bash
cd /d D:\桌面\agent工单\agent工单2
python -c "import database; database.init_tables()"
```

成功输出：`数据库表初始化完成`

数据库会自动创建以下3张表：

| 表名 | 说明 |
|------|------|
| schedule_remind_info | 日程主表（含回收站status=2） |
| schedule_remind_log | 提醒记录表 |
| schedule_operation_log | 操作日志表 |

### 2.6 启动服务

```bash
cd /d D:\桌面\agent工单\agent工单2
python app.py
```

成功输出：

```
数据库表初始化完成
[精确提醒] 调度器已启动
[精确提醒] 启动时注册了 X 条提醒
[定时任务] 每日清除过期回收站已注册
==================================================
日程提醒智能体已启动
访问: http://localhost:5000
==================================================
```

### 2.7 访问系统

浏览器打开：**http://localhost:5000**

## 四、配置说明

### 4.1 端口配置

编辑 `config.py` 修改端口：

```python
FLASK_PORT = 5000       # 服务端口
FLASK_HOST = "0.0.0.0"  # 监听地址（0.0.0.0允许外部访问）
FLASK_DEBUG = False      # 调试模式（生产环境务必设为False）
```

### 4.2 提醒话术配置

编辑 `scheduler.py` 中的 `REMIND_PHRASES` 列表：

```python
REMIND_PHRASES = [
    "温馨提醒：{content}的时间到啦，主人！",
    "主人！是时候{content}了喔~",
    "亲爱的主人，现在是{content}的时候啦！",
    "嘿，主人，该{content}了哦~",

```

编辑 `scheduler.py` 中的 `_cleanup_recycle` 函数：

```python
database.cleanup_old_recycle(30)  # 30天后自动清除
```

## 五、常见问题

### 5.1 启动报错 "No module named 'flask'"

**原因**：未安装依赖包

**解决**：
```bash
pip install flask pymysql requests apscheduler python-dateutil
```

### 5.2 启动报错 "Connection refused" (MySQL)

**原因**：MySQL服务未启动或地址错误

**解决**：
1. 确认MySQL服务已启动
2. 检查 `config.py` 中的 `DB_HOST` 和 `DB_PORT`
3. 确认用户名密码正确

### 5.3 调用AI服务失败

**原因**：DeepSeek API Key无效或网络问题

**解决**：
1. 检查 `config.py` 中的 `DEEPSEEK_API_KEY`
2. 确认网络可访问 `api.deepseek.com`
3. 检查API Key余额

### 5.4 提醒不触发

**原因**：FLASK_DEBUG设为True导致进程分离

**解决**：确保 `config.py` 中 `FLASK_DEBUG = False`

### 5.5 语音输入不工作

**原因**：浏览器不支持或未授权

**解决**：
1. 使用Chrome或Edge浏览器
2. 点击页面上的"🔔 开启通知"按钮授权
3. 确保麦克风权限已开启
