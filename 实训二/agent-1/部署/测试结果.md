# 小家记账本 — 测试结果

## 测试环境

- 操作系统：Windows + WSL
- Python版本：3.9（Anaconda nlp_1环境）
- 数据库：MySQL 8.0（accounting_db.money_notes）
- LLM：DeepSeek（deepseek-chat）

## 验收测试结果

### 测试1：记账（支出）

| 项目 | 内容 |
|------|------|
| 输入 | 今天女儿买了双登山鞋499元 |
| 预期action | add |
| 实际action | add ✅ |
| 回复 | 已记录：2026年6月13日，女儿，买鞋，登山鞋，支出499元 |
| 数据库验证 | 记录已存入money_notes表，字段正确 |

### 测试2：记账（收入）

| 项目 | 内容 |
|------|------|
| 输入 | 7月5日妈妈收到报销1000元 |
| 预期action | add |
| 实际action | add ✅ |
| 回复 | 已记录：2026年7月5日，妈妈，报销，收入1000元 |
| 数据库验证 | type字段为"收入"，金额1000元正确 |

### 测试3：按月汇总（全部成员）
